# Projeto UVWine - TCC (Versao Final)

Este repositorio reune as Partes 1 e 2 do Trabalho de Conclusao de Curso (TCC) em Ciencia de Dados, utilizando o caso ficticio da UVWine para aplicar estatistica, analise de dados e machine learning em Python.

## Objetivo do trabalho

O projeto esta organizado em duas etapas:

- Parte 1: definicao e validacao do tamanho amostral, estratificacao da populacao, testes de hipoteses e bootstrap.
- Parte 2: pipeline de machine learning com dados de treino, validacao e teste para tarefas de regressao, classificacao e clusterizacao.

## Estrutura final do repositorio

### Parte 1

- `LENON_MERLO_PARTE_1_TCC.ipynb` - notebook principal da Parte 1.
- `LENON_MERLO_PARTE_1_TCC.pdf` - versao em PDF da Parte 1.

### Parte 2

- `PARTE 2/LENONMERLO_TCC_PARTE_2_VF.ipynb` - notebook final da Parte 2.
- `PARTE 2/LENONMERLO_TCC_PARTE_2_VF.pdf` - versoes finais para apresentacao e leitura.
